# VPN 连接失败排查（错误 691 / 809 / 连不上）

更新日期：2026-09-30　维护：网络组

## 常见错误码含义

691：用户名或密码错误，或账号被锁定。多数情况是密码过期后仍用旧密码连接，也可能是账号被
安全策略临时锁定（连续输错 5 次会锁 30 分钟）。

809：网络中断或超时，常见于家用宽带不稳定、公司出口防火墙拦截 UDP 500/4500 端口。

错误 720 / 789：本机 PPPoE 或虚拟网卡驱动异常，需要重置网络适配器。

## 自助排查步骤（按顺序做）

1. 先确认能正常打开公司门户（内网可达），排除整体断网。
2. 核对用户名格式：域账号需写成 `CORP\工号` 或 `工号@corp.com`，不要只填工号。
3. 在密码自助平台确认密码是否已过期；过期会直接表现为 691。
4. 重启 VPN 客户端并清除缓存凭证：客户端 → 设置 → 清除已保存密码。
5. 家庭网络下换成手机热点再试一次，用于判断是不是出口端口被封。
6. 关闭本机第三方安全软件的「网络防护」模块后再连一次。

## 仍然连不上时怎么办

连续两次自助排查无效，或错误码为 809 且手机热点也失败，请提工单，分类选「网络与VPN」，
优先级：单人不通选中，整个部门或整层楼不通选高，影响对外业务选紧急。

工单里请附上：客户端完整报错截图、报错时间、所在网络（公司/家庭/热点）、是否只有你一个人不通。
