# 工单分类、优先级与 SLA

更新日期：2026-10-01　维护：IT 服务台

## 分类与默认处理组

账号与权限 → 目录服务组；网络与VPN → 网络组；办公设备 → 桌面支持组；
邮件与协作 → 邮件与协作组；业务系统 → 对应系统运维组；其他 → 服务台值班。

## 优先级判定

紧急：业务中断、影响全员或对外服务不可用（例如整个楼层无法上网、核心业务系统打不开）。
高：影响一个部门或多人的工作，但业务未完全中断。
中：单人受阻，有临时替代方案（例如换一台打印机、用手机热点）。
低：咨询、优化建议、非阻塞问题。

优先级由服务台在受理时复核：报低了的会改高，报高了的会降级并说明原因。

## SLA（响应与解决时限）

紧急：15 分钟内响应，4 小时内解决。
高：1 小时内响应，8 小时内解决（工作日）。
中：4 小时内响应，2 个工作日内解决。
低：1 个工作日内响应，5 个工作日内解决。

「响应」指工程师第一次联系或给出处理动作，不是最终解决。超时会自动升级给组长。

## 什么时候转人工

1. 用户明确要求转人工；
2. 知识库与自助工具走完流程仍未解决；
3. 涉及账号核身、权限变更、离职交接等需要人工审批的场景；
4. 用户连续两次反馈「问题还在」。

转人工后会保留原工单号与时间线，工程师接手时能看到你之前描述的现象与已尝试的操作，
不需要重复说明。
