# 打印机安装与驱动报错处理

更新日期：2026-10-08　维护：桌面支持组

## 网络打印机安装步骤

1. 先确认打印机管理平台（门户 → 办公设备 → 打印机）里能看到该设备，且状态为「在线」。
2. Windows：设置 → 蓝牙和其他设备 → 打印机和扫描仪 → 添加设备，输入打印机的 IP 或
   队列名（形如 `PRT-3F-01`）。
3. 驱动统一使用管理平台提供的企业驱动包，不要用 Windows 自动匹配的通用驱动，
   通用驱动会导致双面打印、装订等高级功能不可用。

## 驱动装不上 / 报「无法安装驱动」

常见原因按概率排序：
1. 旧驱动残留：控制面板卸载同名打印机后，还需在「打印服务器属性 → 驱动程序」里删除残留驱动。
2. 权限不足：安装驱动需要本机管理员权限，普通账号请用「以管理员身份运行」的安装脚本，
   或直接提工单让桌面支持远程协助。
3. 系统版本不匹配：驱动包分 Win10/Win11 两个版本，Win11 装 Win10 包会出现签名校验失败。
4. 打印后台服务异常：把 `Print Spooler` 服务重启一次再装。

## 什么时候需要提工单

同一台打印机连续两次安装失败、或提示驱动签名/权限相关错误时，提工单，分类选「办公设备」，
优先级：一个人装不上选中，整个楼层共用的打印机坏了选高（会附带通知相邻工位使用备用打印机）。

工单里请写明：打印机队列名或 IP、你的电脑型号与系统版本、报错原文截图、是否已卸载旧驱动。
